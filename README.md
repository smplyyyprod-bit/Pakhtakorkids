# Система управления отчетами тренеров

Профессиональная система управления посещаемостью, рабочими часами, дисциплиной и производительностью примерно 50 спортивных тренеров, встроенная в Telegram.

## 🎯 Особенности

### Управление пользователями
- **Администраторы**: Заполняют ежедневные отчеты для тренеров
- **Менеджеры**: Просматривают статистику, сравнивают тренеров, экспортируют отчеты
- **Система ролей**: Управление доступом на основе ролей (RBAC)

### Ежедневные отчеты
- Присутствие (Присутствует/Больничный/Отпуск/Неуважительная причина)
- Форма (Верхняя и нижняя форма - Да/Нет/Нет данных)
- Рабочие часы (Начало/Конец с автоматическим расчетом)
- Производительность (Опоздания, ранние уходы)
- Примечания администратора

### Автоматизация
- **Автоматическое создание отчетов**: Каждый вечер в системе создаются пустые отчеты для всех активных тренеров
- **Отсутствующие отчеты**: Система гарантирует, что каждый день имеет запись для каждого тренера
- **Расчеты**: Автоматический расчет рабочих часов, опозданий и других метрик
- **Уведомления**: Напоминания о незаполненных отчетах

### Статистика
- **Ежемесячные отчеты**: Работанные часы, дни, опоздания, отсутствия
- **Панель управления**: Обзор компании, рейтинги, процент завершения
- **Рейтинги**: Самые работающие, самые пунктуальные, большинство нарушений
- **Тренды**: Анализ явки, часов и нарушений по месяцам

### Экспорт
- **Excel (.xlsx)**: Форматированные ежемесячные отчеты с таблицами и статистикой
- **PDF**: Профессиональные отчеты для печати

### Администрирование
- **Управление тренерами**: Добавление, редактирование, деактивация, перемещение между отделениями
- **Управление отделениями**: CRUD операции
- **Управление критериями**: Настраиваемые критерии оценки без изменения кода
- **Журнал аудита**: Логирование всех изменений

### Паттерны проектирования
- **Repository Pattern**: Абстракция доступа к данным
- **Service Layer**: Бизнес-логика отделена от контроллеров
- **Clean Architecture**: Независимость от фреймворков
- **Dependency Injection**: Слабая связанность компонентов
- **FSM (Finite State Machine)**: Управление состоянием форм

## 📊 Схема базы данных

### Основные таблицы
- **users**: Пользователи системы (администраторы, менеджеры)
- **branches**: Отделения/офисы
- **coaches**: Тренеры
- **daily_reports**: Ежедневные отчеты (основная таблица)
- **evaluation_criteria**: Настраиваемые критерии оценки
- **criterion_values**: Предопределенные значения для критериев
- **audit_logs**: Логирование всех изменений

### Связи
```
User -> Branch (многие к одному)
Coach -> Branch (многие к одному)
Coach -> DailyReport (один ко многим)
DailyReport -> Branch (многие к одному)
```

## 🚀 Установка и запуск

### Требования
- Docker & Docker Compose
- Python 3.13+
- PostgreSQL 15+
- Redis 7+

### Быстрый старт (Docker)

1. **Клонируйте репозиторий**
   ```bash
   git clone <repository_url>
   cd pakhtakorkids
   ```

2. **Создайте файл `.env`**
   ```bash
   cp .env.example .env
   ```

3. **Отредактируйте `.env` и добавьте токен бота**
   ```bash
   TELEGRAM_BOT_TOKEN=your_bot_token_here
   TELEGRAM_ADMIN_IDS=123456789,987654321
   DB_USER=coaching_user
   DB_PASSWORD=secure_password
   DB_NAME=coaching_management
   ```

4. **Запустите с помощью Docker Compose**
   ```bash
   docker-compose up -d
   ```

5. **Проверьте логи**
   ```bash
   docker-compose logs -f bot
   ```

### Локальная установка (разработка)

1. **Создайте виртуальное окружение**
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/Mac
   venv\Scripts\activate     # Windows
   ```

2. **Установите зависимости**
   ```bash
   pip install -r requirements.txt
   ```

3. **Создайте файл `.env`**
   ```bash
   cp .env.example .env
   ```

4. **Запустите PostgreSQL и Redis**
   ```bash
   # С Docker
   docker-compose up -d postgres redis
   
   # Или используйте локальные экземпляры
   ```

5. **Запустите приложение**
   ```bash
   python main.py
   ```

## 🤖 Использование бота

### Для администраторов

1. **Отправьте `/start`** для входа
2. **Нажмите "📋 Ежедневные отчеты"**
3. **Выберите отделение**
4. **Выберите тренера** и начните заполнение формы
5. **Используйте кнопки** вместо ввода текста для быстроты
6. **Сохраните отчет** - система автоматически откроет следующего тренера

### Для менеджеров

1. **Отправьте `/start`** для входа
2. **Используйте меню** для:
   - 👥 Просмотра списка тренеров
   - 📊 Просмотра ежемесячных отчетов
   - 📈 Просмотра панели управления
   - 📥 Экспорта отчетов в Excel/PDF
   - ⚙️ Администрирования системы

## 🔧 Конфигурация

Все параметры настраиваются через переменные окружения (`.env`):

```env
# Telegram
TELEGRAM_BOT_TOKEN=your_token
TELEGRAM_ADMIN_IDS=123456789,987654321

# Database
DATABASE_URL=postgresql://user:password@localhost/coaching_management
DATABASE_ECHO=false

# Redis
REDIS_URL=redis://localhost:6379/0

# Logging
LOG_LEVEL=INFO
LOG_FILE=logs/app.log

# Scheduler
SCHEDULER_TIMEZONE=Asia/Tashkent
AUTO_REPORT_GENERATION_TIME=23:30

# Environment
ENVIRONMENT=production
DEBUG=false
```
