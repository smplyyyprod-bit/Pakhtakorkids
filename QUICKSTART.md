# Быстрый старт (5 минут)

## ⚡ Самый быстрый способ

### 1. Получите Telegram Bot Token

1. Откройте Telegram и найдите **@BotFather**
2. Отправьте `/newbot`
3. Выберите имя и имя пользователя для вашего бота
4. Скопируйте полученный token (выглядит как: `123456789:ABCdefGHIjklmnoPQRstUVwxyz123456789`)

### 2. Узнайте свой Telegram ID

1. Найдите **@userinfobot** в Telegram
2. Отправьте любое сообщение
3. Скопируйте ваш ID (числовое значение)

### 3. Клонируйте репозиторий

```bash
git clone https://github.com/your-org/pakhtakorkids.git
cd pakhtakorkids
```

### 4. Создайте файл конфигурации

```bash
cp .env.example .env
```

### 5. Отредактируйте `.env`

```bash
nano .env
```

Обновите эти строки:

```env
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklmnoPQRstUVwxyz123456789
TELEGRAM_ADMIN_IDS=your_telegram_id
```

Сохраните файл (Ctrl+O, Enter, Ctrl+X)

### 6. Запустите

```bash
docker-compose up -d
```

### 7. Проверьте статус

```bash
docker-compose ps
```

Все контейнеры должны иметь статус **Up**

### 8. Откройте Telegram

1. Найдите вашего бота (по имени, которое вы установили)
2. Отправьте `/start`
3. Вы должны увидеть главное меню

🎉 **Готово!**

## 🆘 Если что-то не работает

### Контейнер не запускается?

```bash
# Посмотрите логи
docker-compose logs bot

# Проверьте, что .env файл заполнен правильно
cat .env

# Перезагрузите
docker-compose restart bot
```

### Бот не отвечает?

```bash
# Проверьте токен в .env
grep TELEGRAM_BOT_TOKEN .env

# Убедитесь, что токен скопирован полностью (без пробелов)

# Перезагрузите бота
docker-compose restart bot

# Посмотрите логи
docker-compose logs -f bot
```

### Ошибка базы данных?

```bash
# Проверьте, что PostgreSQL запущен
docker-compose ps postgres

# Если нет, перезагрузите все
docker-compose down
docker-compose up -d

# Подождите 10-15 секунд
# Проверьте статус
docker-compose ps
```

### Помощь с ошибками логирования?

```bash
# Очистите логи
rm -rf logs/*

# Пересоздайте контейнеры
docker-compose down
docker-compose up -d
```

## 🎯 Типичный рабочий день администратора

1. Откройте Telegram утром
2. Отправьте `/start`
3. Нажмите "📋 Ежедневные отчеты"
4. Выберите ваше отделение
5. Заполните отчеты для каждого тренера (5-10 минут на всех)
6. Каждый отчет заполняется через кнопки - просто нажимайте!

**Система гарантирует, что ни один отчет не пропустит ни один день!**
